# Reference

Exact values a reader looks up: formats, grammars, field lists, tables, and ordered steps. The specs in [../specs/](../specs/) state the rules, and each page names the rules that bind its content.

- [command-surface.md](./command-surface.md): the exit codes, the usage of every verb, the peer writer, the plan flag and the dispatch matrix, and the dependency manifest.
- [diagnostics.md](./diagnostics.md): the diagnostic classes, the messages that relay another tool's output, and the faults and messages of each domain.
- [identifiers-and-tokens.md](./identifiers-and-tokens.md): the id grammar, the slug function, the prefixed id, the session and source references, and how a graph node is written.
- [machine-layout.md](./machine-layout.md): where wipctl keeps its files on one machine, slot names, slot states, and the suppression file.
- [measures.md](./measures.md): the flow measures and the point arithmetic.
- [plan-configuration.md](./plan-configuration.md): the project file and the plan configuration, section by section.
- [plan-documents.md](./plan-documents.md): the heading sequences of the zone documents, the question section, and the watch section.
- [plan-record-files.md](./plan-record-files.md): the lane file and its fields, the pending fragment, the touch list, the transition journal, the commit grammar, and the zone layout.
- [plan-resolution.md](./plan-resolution.md): how an invocation finds its plan, and how a prefixed dependency finds its entry.
- [scaffold-payload.md](./scaffold-payload.md): what the scaffold lands, the host pointer block, and the stale conversation.
- [session-adapters.md](./session-adapters.md): the session adapter section, the inspect reading, and the setup profile of each coding-session system.
- [verb-mechanics.md](./verb-mechanics.md): the move preflight, the peer walk, the reconciliation cases, the batch run, the rename write set, and the slot repair.
- [views.md](./views.md): the glyph tiers, and the peer view.
- [tracking.yaml](./tracking.yaml): the registry of facts that expire.
- [known-issues/](./known-issues/): the outside defects that this project works around, one `KI-<slug>.md` record each.
- [TEMPLATE-agents-digest.md](./TEMPLATE-agents-digest.md) and [TEMPLATE-known-issue.md](./TEMPLATE-known-issue.md): the templates the documentation tool seeds.
